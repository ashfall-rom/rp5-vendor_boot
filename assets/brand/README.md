# AshFall brand assets

The icon and mark used across `ashfall-rom`. Copied from the ROM repository so
this repo's README renders without depending on another checkout.

| File | What it is |
|---|---|
| `ashfall-icon.svg` | App icon: circular tile, 512 viewBox, self-contained. |
| `ashfall-mark.svg` | The same glyph, one colour via `currentColor` (tint, mask, themed icon). |
| `social/<repo>.png` | This repository's GitHub social preview card, 1280x640. |

Source of truth, palette and regeneration:
<https://github.com/ashfall-rom/ashfall/blob/main/assets/brand/README.md>.
GitHub has no API for a social preview, so the card is uploaded by hand through
*Settings → Social preview*; the committed copy is what gets uploaded.
